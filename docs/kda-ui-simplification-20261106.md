# KDA UI 단순화 · 음성 대상 명시

후속 승인: 대상 고정 추천은 `kda-voice-routing-20261106.md`의 현재 대화 따라가기·이름 전환으로 대체한다. K가 v0.7.73 GitHub 릴리스까지 승인했으며 설치는 직접 한다. 아래 미배포/대상 고정은 초기 UI 개정의 이력이다.

K 요청: Dot 조사와 기존 화면을 참고해 자주 쓰는 기능을 앞에 두고 나머지는 접어두기. 음성통화가 열린 대화에 적용되는 방식도 검토.

현재 작업: Windows SMM, `.worktrees/control-results-20261105`. 기존 dirty worktree의 음성 장치 안내·출력 증폭 변경을 보존했다. 진행 증거와 최종 검증은 `evidence/simple-ui-20261106/status.json`에 연결한다. 이 개정의 태그 push·릴리스·설치는 수행하지 않는다.

## 음성 연결의 실제 의미

통화 시작 시 선택된 KDA 대화 ID를 세션에 고정한다. 화면에서 다른 대화로 이동해도 통화 대상은 바뀌지 않는다. 음성 중계 스레드는 별도의 일시 세션이며, 열린 대화의 과거 기록 전체를 복사하거나 기존 작업 스레드를 재개하는 구현이 아니다.

- 일반 대화는 음성 세션에서 응답한다.
- 진행·결과 질문은 연결된 대화의 실제 상태와 최신 답변을 조회한다. 작업을 무조건 중단하지 않는다.
- 새 작업은 연결된 대화의 기존 대기열로 전달한다. 명시적 변경 지시는 기존 steer 경로로 전달한다.
- 작업 정지·전체 정지와 음성 출력 중지를 구분한다. 기존 승인·프로젝트 경계를 유지한다.

기본 추천은 **시작한 대화에 고정 + 대상 표시 + 다른 대화에서 복귀 버튼**이다. 화면 전환에 따라 대상이 조용히 바뀌면 다른 프로젝트의 작업을 바꿀 수 있으므로 자동 전환하지 않는다. 전체 대화 기록을 자동으로 이해한다고 안내하지 않는다. 별도 전역 비서나 대화 간 명령 이동은 이번 개정에 추가하지 않는다.

## 화면 변경

| 영역 | 항상 표시 | 필요할 때 펼침 |
| --- | --- | --- |
| 비서 카드 | 통화 대상·통화하기·Telegram·최근 답변 | 활동·연결 컴퓨터·DOT 연결·위치 복원 |
| 음성통화 | 연결 대화·연결 오류·음소거·말하기 중지·통화 종료·작업 제어 | 입력/출력 장치·출력 증폭·장치 새로고침·통화 자막 |
| 대화 헤더 | 대화·승인 모드·연결 상태 | 대화 복사·도구 호출 표시 |
| 사이드바 | 새 대화·기존 탐색기·환경설정 | 백업·가져오기 |

넓은 화면의 기본 위치는 오른쪽 공간을 확보해 대화 헤더·본문을 가리지 않는다. 드래그한 위치와 최소화 상태는 기존 저장값을 유지한다. 작은 화면은 카드 내부 스크롤과 최소화로 접근한다. 기존 연결기는 메뉴를 접거나 카드를 최소화해도 마운트를 유지하며 요청 대상을 보존한다.

색상은 기존 KDA 토큰을 유지하고, 카드의 간격·둥근 모서리·버튼 위계를 정리했다. 새 래스터 이미지·아이콘 라이브러리·외부 UI 의존성은 추가하지 않았다.

## 검증 범위

- `scripts/build-simple-ui-fixture.mjs`는 실제 Sidebar·MainChat·AssistantWidget·VoiceCallPanel을 예시 대화와 함께 번들링한다. native DB·파일·마이크·클립보드는 대역이다.
- `scripts/probe-simple-ui.py`: 옵션의 실제 복사·도구 카드 경로, 백업 키보드 접근, 장치 설정·출력 증폭 보존, 대화 전환 후 대상 고정, 접힌 메뉴의 연결기 동작, 화면 크기 확인.
- 기존 `scripts/probe-assistant-widget.py`: 이동·최소화·위치 복원·장치 오류·연결 대상·스토리지 실패 등 회귀 확인.
- `scripts/validate-simple-ui.py`: 기존 release gate와 음성 제어 회귀검사, 소스 해시 불변 확인, 로그와 종료 코드 보존.

`review.html`과 PNG는 개발용 격리 화면이며 설치 앱 캡처가 아니다. 실제 마이크·스피커·음향 끼어들기·설치 WebView2 왕복은 미검증이다. 기존 합성 음성·음성 증폭 검증을 실장치 통과로 바꾸지 않는다.
