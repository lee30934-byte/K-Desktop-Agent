# 세라믹 아바타 관절 모션 — 2026-11-06

현재 세라믹 원본과 메뉴 위치를 유지하면서 머리와 몸통을 별도 CSS 레이어로 표시한다. 전체 이미지만 흔들던 모션에 독립적인 고개 갸웃·끄덕임·발화 리듬·몸통 호흡과 그림자 움직임을 추가했다. 커서가 아바타 위를 움직이면 고개가 따라가며, 포인터가 떠나거나 드래그가 시작되면 커서 오프셋을 해제한다. 터치는 커서 추적을 실행하지 않는다.

대기·듣기·말하기·음소거·오류 상태마다 고개 움직임이 다르다. 팔짱·태블릿처럼 목 경계를 가로지르는 포즈는 기존 원본 전체를 유지한다. 선택한 색상, 메뉴, 드래그, 축소 및 통화 수명은 기존 경로를 사용한다. 모션 끄기·OS reduced motion·백그라운드에서는 관절 애니메이션도 정지한다.

이번 개정은 기존 비트맵을 코드에서 분리해 움직이는 2D 표현이다. 새 3D 모델, 새 표정 이미지, 눈 깜빡임 또는 음소별 립싱크를 구현한 것은 아니다. 레이어 접합은 원본의 목 경계를 사용하는 근사이며, 실통화·설치 WebView2 검증과 최종 미감 승인은 별도다.
