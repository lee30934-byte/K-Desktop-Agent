# 대화를 이어가는 음성 명령

K가 승인한 방식: 현재 대화를 기본 대상으로 사용하고, 말로 다른 대화를 지정하며, 통화와 작업의 수명은 분리한다. 이전 문서의 '통화 시작 대상 고정'은 이 개정으로 대체한다. v0.7.73 GitHub 릴리스까지 승인됐으며 설치는 K가 직접 한다.

## 사용 방식

- 기본은 '현재 보고 있는 대화 따라가기'. 발화 시작 때 대상을 잡으므로 말하던 중 화면을 옮겨도 이번 명령은 원래 대화에 전달된다. 다음 발화부터 새 화면의 대화를 따른다.
- '릴리스 점검 대화에 테스트 실행해줘'처럼 이름을 말하면 해당 대화로 전달하고 이후 대상으로 고정한다. '현재 보고 있는 대화로 돌아가자'는 follow로 복귀한다. 음성 영역에서도 대상을 선택할 수 있다.
- 새 작업과 기존 대화에 관한 요청은 원래 KDA send/steer 경로에서 처리하므로 대상 대화의 기록·프로젝트 규칙·승인을 따른다. 음성 중계 세션에 전체 대화 기록을 복사하지 않는다. 인사 등 가벼운 대화만 중계 세션에서 직접 응답한다.
- 조회는 작업을 중단하지 않는다. 대화 전환도 미디어 연결을 재시작하거나 기존 작업을 정지하지 않는다. 통화에서 확인한 대화의 진행·완료·승인 대기를 대화 이름과 함께 안내한다. 통화 종료 후 작업은 기존 작업 패널에서 관리한다.
- 이름이 겹치면 후보를 제시하고 확인 전 실행을 보류한다. 선택이 사라지거나 삭제된 경우 다른 대화로 대신 보내지 않는다. 중복 이름 구분은 현재 목록의 정렬된 구분 이름이며 영구 식별자라고 안내하지 않는다.

## 구현과 검증

`VoiceRouter`는 실제 UI 목록에서 이름을 해석하며 음성 모델이 임의 UI ID를 전달하는 경로를 허용하지 않는다. 세션별 단일 사용 토큰·15초 만료·종료 후 폐기, 대상별 기존 명령 게이트, 수동/전체 정지 장벽과 기존 승인을 유지한다. 이름 조회는 제목만 제공하며 대화 본문을 조회하지 않는다.

`scripts/voice.test.ts`의 실행 검사에 발화 시작 대상 고정, 이름 선택·고정·복귀, 동명이름 확인, 삭제·선택 소실, 대화 간 재전송 거절, 전체 정지와 과거 대상 완료 알림을 포함했다. `scripts/probe-voice-routing.py`는 실제 AssistantWidget/VoiceCallPanel/VoiceSession을 synthetic media·native 대역으로 실행한다. 기존 UI 간소화와 비서 카드 회귀검사도 함께 수행한다. 최종 로그·소스 해시는 `evidence/release-v0773-20261106/validation.json`에 연결한다.

이번 라우팅의 자연발화 인식·실제 구독 서버 대상 선택·실장치 음향·설치 WebView2 통화는 아직 미검증이다. 이전 v0.7.72의 구독 서버 합성 음성 성공을 이번 대화 간 라우팅 실통화 성공으로 확대하지 않는다. 원음·자막의 제품 저장 정책과 기존 5분 제한을 유지한다.

## 포함하는 기존 개선

KDA 음성에만 적용되는 0~300% 출력 조절(기본 150%)과 limiter, 장치 오류·새로고침 안내, 주요 기능만 앞에 두고 활동·연결·백업·도구·장치·자막을 접는 UI 간소화를 포함한다. 시스템 및 다른 앱의 음량은 변경하지 않는다.
